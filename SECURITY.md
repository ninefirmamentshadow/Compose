# Security

Drafts is intentionally offline-first. The Android manifest requests no Internet or location permission, and the application has no account system, analytics, telemetry, advertising, cloud sync, auto-posting, scraping, or platform API integration.

If you believe the application has a security defect, open a GitHub issue describing the affected version, reproduction steps, and observable behavior. Do not include credentials, signing material, private contact information, or other sensitive data in an issue.

Android signing keys and their passwords are maintainer secrets and must never be committed to the repository.
