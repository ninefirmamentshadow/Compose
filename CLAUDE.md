# CLAUDE.md

Drafts — a multi-format text composition and consistency-checking tool for a
mobile-first independent operator. Write one draft; render it per platform,
count it against limits, check it against canonical values, lint it against an
editable rule set, copy the result.

See `AGENTS.md` for execution rules, the code/data separation (canonical values
and rules are operator data, not code), and the protected-data boundary. See
`README.md` for the full feature surface and how to edit the rules.

Sovereign-Ops is the umbrella source of truth; Drafts is vendored there under
`compose/`, and this repository is its standalone home.
